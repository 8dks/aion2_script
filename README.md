# AION2 K3M2 脚本源码

这是 K3M2 v50 的可编辑 Python 3.11 源码整理版。仓库按用途提供两个相互独立的目录，均已删除界面中的 QQ 群和 Q聊广告入口。

## 目录说明

| 目录 | 说明 |
|---|---|
| [`原版_去QQ广告`](./原版_去QQ广告/) | 保留原版激活、心跳、云端规则、遥测和样本同步逻辑，仅移除 QQ 相关广告。 |
| [`永久版_免认证`](./永久版_免认证/) | 默认显示“永久版”，启动不需要激活码，不读取授权缓存或授权硬件指纹，并关闭原授权服务器的验证、心跳、遥测、报告、云端规则和样本同步。 |

永久版仍保留冰拓验证码服务的可选联网能力，因为它是用户主动配置的第三方验证码服务，不属于 K3M2 软件授权认证。VIIPER 与本机守护进程之间的本地安全握手也予以保留，以免破坏输入驱动功能。

## 快速开始

本项目仅支持 Windows，建议使用 64 位 Python 3.11。

1. 进入需要使用的版本目录。
2. 双击 `安装依赖.bat` 安装 Python 依赖。
3. 双击 `检查源码.bat` 检查源码和随附资源。
4. 双击 `启动源码.bat` 启动程序。

输入驱动的安装、卸载可能触发 Windows 管理员权限确认。仓库已包含模型、OCR 语言包、Lua 驱动和程序需要的本机输入驱动资源，不包含原还原过程产生的字节码、中间文件和完整便携 Python 环境。

## 注意事项

- `设置.json` 是初始配置模板，运行后会写入本机窗口、按键和规则设置。
- 加密 Lua 脚本依赖随目录提供的 `keymod.dll`。
- OCR 的 Tesseract 可执行程序需由使用者在 Windows 中另行安装；ONNX OCR 模型已随仓库提供。
- 当前仓库未声明开源许可证；未经权利人许可，不应将代码或随附二进制资源用于超出授权范围的再分发。
