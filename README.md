# K3M2 v50 源码整理版

仓库里放了两套可以单独运行的代码。两套都去掉了界面上的 QQ 群、Q聊按钮和对应链接，区别只在授权与联网逻辑。

| 目录 | 适合什么情况 |
| --- | --- |
| [`原版_去QQ广告`](./原版_去QQ广告/) | 需要保留原来的激活、心跳、云端规则和样本同步，只想去掉 QQ 广告。 |
| [`永久版_免认证`](./永久版_免认证/) | 本机直接使用，不输入激活码，也不连接原授权服务器。 |

如果只是想用免认证版，直接进入 `永久版_免认证` 即可，不需要先运行原版。

## 运行环境

- Windows 10/11 64 位
- Python 3.11 64 位
- 输入驱动的安装和启动需要管理员权限

不要使用 32 位 Python，也不建议用 3.12、3.13 代替 3.11。项目里的 DLL、驱动和部分 Python 扩展都是按 64 位环境准备的。

## 下载代码

已经配置 GitHub SSH 密钥的电脑可以直接执行：

```powershell
git clone git@github.com:8dks/aion2_script.git
cd aion2_script
```

也可以在 GitHub 页面下载 ZIP，解压后使用。

## 安装和启动

下面以永久版为例，原版的操作相同。

1. 安装 Python 3.11 64 位。安装时勾选 `Add Python to PATH`。
2. 打开 `永久版_免认证` 文件夹，双击 `安装依赖.bat`。
3. 双击 `检查源码.bat`。看到源码和资源检查通过后再启动。
4. 右键 `启动源码.bat`，选择“以管理员身份运行”。

喜欢在终端里操作，也可以这样运行：

```powershell
cd 永久版_免认证
py -3.11 -m pip install -r requirements.txt
py -3.11 check_source.py
py -3.11 DD.py
```

主程序入口是 `DD.py`。首次运行后，窗口位置、按键、规则和其他选项会写进当前目录的 `设置.json`。换电脑或覆盖文件前，建议先备份这个文件。

## 打包永久版

永久版已经准备好 PyInstaller 配置。双击 `打包永久版.bat`，脚本会安装打包工具并生成：

```text
永久版_免认证\dist\K3M2_永久版.exe
```

也可以手动执行：

```powershell
cd 永久版_免认证
py -3.11 -m pip install -r requirements.txt
py -3.11 -m pip install "pyinstaller>=6.10"
py -3.11 -m PyInstaller --noconfirm --clean K3M2_永久版.spec
```

`dist` 和 `build` 是本机生成目录，Git 不会提交它们。打包配置关闭了 UPX，避免改写随程序携带的驱动、DLL 和安装程序。

## 两个版本的联网区别

原版仍保留原有的授权验证、心跳、遥测、报告、云端规则和验证码样本同步。永久版关闭了这些入口，默认状态就是“永久版”。

永久版仍保留两类不属于软件授权的通信：

- 用户主动填写账号后使用的冰拓验证码服务；
- VIIPER 与本机守护进程之间的本地通信。

不使用冰拓验证码时，不填写相关账号即可。

## 常见问题

### 提示找不到 `py -3.11`

说明 Python 3.11 没有安装好，或者安装的是 32 位版本。重新安装 64 位 Python 3.11，并确认命令 `py -3.11 --version` 能正常输出版本号。

### 提示缺少 Python 模块

重新运行 `安装依赖.bat`。如果下载依赖时失败，先检查网络和 pip 镜像设置，再执行一次。

### 按键或鼠标没有反应

先退出程序，再右键 `启动源码.bat` 或打包后的 EXE，以管理员身份运行。驱动被安全软件拦截时，需要把程序目录加入信任后重新启动。

### Tesseract OCR 不工作

仓库包含 `chi_sim`、`chi_tra` 和 `eng` 语言数据，但使用 Tesseract 识别方式时，系统还需要安装 64 位 `tesseract.exe`。项目自带的 ONNX OCR 不受这一项影响。

### 如何检查打包后的程序

在终端运行：

```powershell
.\K3M2_永久版.exe --selfcheck
```

检查结果保存在同目录的 `logs\自检报告.txt`。
