# 原版（去 QQ 广告）

这个目录保留 K3M2 v50 原来的业务和授权流程，删除了主界面的 QQ 群、Q聊按钮、抖音直播检测入口以及对应链接。

## 安装

准备一套 64 位 Python 3.11，然后在当前目录双击 `安装依赖.bat`。

也可以打开 PowerShell 手动安装：

```powershell
py -3.11 -m pip install -r requirements.txt
```

## 启动

先运行一次源码检查：

```powershell
py -3.11 check_source.py
```

检查通过后，右键 `启动源码.bat`，选择“以管理员身份运行”。终端启动命令是：

```powershell
py -3.11 DD.py
```

管理员权限主要用于输入驱动。普通权限可以打开界面，但驱动可能无法安装或正常接管键鼠输入。

## 这个版本保留了什么

- 原激活码验证和授权缓存；
- 授权心跳、遥测和运行报告；
- 云端规则备份、恢复；
- 验证码样本同步和云端训练数据；
- 冰拓验证码等原有功能。

也就是说，这不是免认证版。原授权服务器无法访问时，相关功能仍可能受影响。需要完全本地运行时，请使用仓库里的 `永久版_免认证`。

## 使用时注意

- `DD.py` 是主入口。
- `内置规则.json` 是 `内置规则.dat` 解密后的明文规则，方便查看和修改；程序默认仍读取 `.dat`。
- `设置.json` 保存窗口、按键、规则和授权等本机设置，覆盖前先备份。
- ONNX 模型和 OCR 语言数据已经放在目录里。
- 使用 Tesseract 识别方式时，还要在 Windows 中安装 64 位 `tesseract.exe`。
- 按键、鼠标没有反应时，先确认程序以管理员身份运行，并检查安全软件是否拦截驱动。
