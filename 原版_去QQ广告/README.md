# 原版（已去 QQ 广告）

本目录保留 K3M2 v50 的原始业务和授权流程，仅删除主界面中的 QQ 群、Q聊按钮及对应链接。

## 使用方法

1. 安装 64 位 Python 3.11。
2. 双击 `安装依赖.bat`。
3. 双击 `检查源码.bat`，确认源码与资源完整。
4. 双击 `启动源码.bat`。

主入口是 `DD.py`。目录已包含 ONNX 模型、Tesseract 语言数据、加密 Lua 脚本、`keymod.dll` 和输入驱动资源。中文/英文传统 Tesseract OCR 还需要系统中安装 `tesseract.exe`。

此版本仍会按原逻辑访问激活服务器，包括激活验证、心跳、遥测、报告、云端规则以及验证码样本同步。
