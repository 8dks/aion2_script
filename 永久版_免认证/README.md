# 永久版（免认证）

这个目录可以直接在本机运行。软件默认显示“永久版”，不需要填写激活码，也不会连接原来的授权服务器。QQ 群、Q聊和抖音直播检测入口同样已经删除。

## 最快的启动方法

1. 安装 64 位 Python 3.11，安装时勾选 `Add Python to PATH`。
2. 双击 `安装依赖.bat`，等依赖安装完成。
3. 双击 `检查源码.bat`，确认代码和资源完整。
4. 右键 `启动源码.bat`，选择“以管理员身份运行”。

如果电脑上已经配好 Python，也可以在当前目录打开 PowerShell：

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 check_source.py
py -3.11 DD.py
```

第一次启动后，程序会在 `设置.json` 中保存窗口、按键、规则等设置。需要保留个人配置时，不要随意删除或覆盖这个文件。

目录里的 `内置规则.json` 是 `内置规则.dat` 解密后的明文副本，方便直接查看和修改。当前程序运行时仍读取 `.dat`，修改 JSON 不会自动回写加密文件。

## 永久版改了哪些地方

- 授权状态固定为“永久版”，启动时直接进入本地流程；
- 不读取旧激活缓存，不为软件授权采集硬件指纹；
- 不执行原授权验证和心跳；
- 不发送原版遥测、运行报告和授权报告；
- 关闭云端规则备份、恢复、样本共享和云端训练数据；
- 删除 QQ 群、Q聊、抖音直播检测入口及对应链接。

冰拓验证码服务没有被删除。它只有在用户主动填写冰拓账号并使用相关功能时才会联网，与软件激活无关。VIIPER 和本机守护进程之间的本地通信也保留，否则输入驱动无法正常工作。

## 打包成 EXE

右键或双击 `打包永久版.bat`。脚本会先确认依赖，再调用 PyInstaller。完成后文件在：

```text
dist\K3M2_永久版.exe
```

手动打包命令：

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 -m pip install "pyinstaller>=6.10"
py -3.11 -m PyInstaller --noconfirm --clean K3M2_永久版.spec
```

这是单文件打包。模型、OCR 数据、Lua 脚本、DLL 和输入驱动都放进了 EXE。配置中关闭了 UPX，避免旧版 UPX 改写驱动或 DLL。

生成的 `build`、`dist` 目录只保留在本机，不会提交到 GitHub。

## 检查打包结果

在 `dist` 目录打开 PowerShell，执行：

```powershell
.\K3M2_永久版.exe --selfcheck
```

程序会进行识别、驱动状态、热键和配置检查，结果写入：

```text
dist\logs\自检报告.txt
```

没有绑定游戏窗口时，内存检测显示“跳过”属于正常情况。没有从主界面启动驱动时，驱动项显示“未初始化”也属于正常情况。

## 常见问题

### 双击后没有反应

从 PowerShell 执行 `py -3.11 DD.py`，终端里会保留具体错误。最常见的原因是 Python 版本不对，或者依赖没有装完整。

### 键鼠功能不能用

退出程序，然后以管理员身份重新运行。若安全软件隔离了 `ttinput.sys`、`F.dll`、`DD64.dll` 等文件，需要恢复文件并把当前目录加入信任。

### OCR 提示找不到 Tesseract

只有选择 Tesseract 识别方式时才需要另装 64 位 `tesseract.exe`。项目自带的 ONNX OCR 模型可以直接使用。

### 换电脑后如何保留设置

复制旧目录里的 `设置.json` 到新目录。覆盖前最好先保留一份备份，避免不同版本的字段变化造成设置丢失。
