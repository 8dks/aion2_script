# 永久版（免认证）

本目录是 K3M2 v50 的本地永久版本，同时删除了主界面的 QQ 群和 Q聊广告。

## 永久版行为

- 默认授权状态为“永久版”，无需输入激活码。
- 启动驱动脚本时直接进入本地执行流程。
- 不读取激活缓存，不为软件授权采集硬件指纹。
- 不启动原授权心跳，不发送遥测或 Sentinel 报告。
- 关闭原授权服务器的云端规则、样本共享和云端训练数据功能。
- 保留用户主动配置的冰拓验证码服务，以及 VIIPER 本机守护进程的本地安全握手。

## 使用方法

1. 安装 64 位 Python 3.11。
2. 双击 `安装依赖.bat`。
3. 双击 `检查源码.bat`，确认源码、资源和离线授权改造完整。
4. 双击 `启动源码.bat`。

如需生成单文件程序，安装 PyInstaller 后运行 `打包永久版.bat`。生成文件位于 `dist/K3M2_永久版.exe`，该本机打包目录不会提交到 Git。
